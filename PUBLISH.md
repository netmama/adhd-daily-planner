# Fork and Release Notes

This repository is a personal adaptation of NetMama's ADHD Daily Planner. The adapted work is currently maintained on the `menna/life-aware-planner` branch so the original `main` branch remains unchanged.

## Current status

- The adapted skill is documented in `SKILL.md`.
- The planning model is documented in `PLANNING_MODEL.md`.
- `README.md`, `QUICK-START.md`, and `EXAMPLES.md` describe the adapted behavior.
- The original MIT license and attribution are retained.

## Review before using or publishing

1. Review the changes on the adaptation branch.
2. Test the skill in the intended assistant environment.
3. Check that the instructions fit the platform's skill format and limits.
4. Adjust examples and behavior based on actual use.
5. Keep private health, financial, and identifying details out of public repository files.

## Publishing or merging

Do not merge this branch into `main` or publish a release until the owner has reviewed and explicitly chosen to do so.

If the owner later decides to merge:
1. Open a pull request from `menna/life-aware-planner` into `main`.
2. Review the complete diff, including attribution and license notices.
3. Confirm that the skill works in its intended environment.
4. Merge only after approval.
