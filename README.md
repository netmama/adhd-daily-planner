# Life-Aware Daily Planner

An adapted, ADHD-friendly planning skill that connects long-term direction to realistic daily actions across **work, learning, home, self-care, worship or personal values, relationships, rest, and enjoyment**.

This fork evolves the original ADHD Daily Planner from a workday scheduler into a flexible daily-life planning and execution companion. It keeps the useful foundations—clear priorities, task sizing, startup and transition awareness, realistic capacity, and gentle end-of-day review—while adding whole-life planning, multidimensional capacity, recovery-aware scheduling, and learning from real task logs.

## What changed in this fork

- **Whole-life direction:** daily actions connect to current goals and meaningful life areas, not just work tasks.
- **Weekly-to-daily connection:** broad goals become milestones and small next actions.
- **Multidimensional capacity:** mental focus, physical stamina, symptoms, emotional/social load, and recovery can be considered separately when relevant.
- **Recovery-aware planning:** commitments and outings are planned with their preparation and after-effects in mind.
- **Adaptive estimates:** user-provided task logs take precedence over generic time assumptions.
- **Low-friction coaching:** short questions, compact plans, gentle restarts, and no duplicate tracking system.
- **Privacy by design:** personal health and other sensitive user details are not embedded in this public repository.

## Use

The skill is intended to activate when the user asks to plan a day or week, choose priorities, make progress on goals, review task/time logs, or recover after getting derailed.

Start with the context already known. Ask only for missing information that changes the plan. The user should not need to complete a long intake form.

## Design principles

1. Progress over volume.
2. The user's whole life matters—not only paid work.
3. Capacity is multidimensional and may change from day to day.
4. Health constraints and recovery are real planning inputs, not motivation problems.
5. Real task history is more useful than false precision.
6. The user remains in charge; the planner supports rather than controls.
7. Keep planning lightweight enough to be used on an ordinary, imperfect day.
